# Требования к внешним интеграциям

## Безопасность

- Секрет партнера хранится в tenant-core-app, не в мобильном приложении.
- Вызов ограничен одним жилым комплексом и квартирой собственника. Чужой ЖК и чужие клиенты недоступны.
- Биометрия лица и видео остаются на платформе партнера и не записываются в базы PropDevelopment.
- Номер автомобиля передается только для машин этого собственника и этого дома.
- Канал только по TLS. Открытие двери и шлагбаума журналируется.

## Аутентификация и авторизация

- Собственник входит через auth-service-1 (Keycloak) по OIDC. Приложение передает токен в REST-запросе к tenant-core-app.
- tenant-core-app вызывает платформу партнера по OAuth 2.0 client credentials.
- Перед вызовом сервис проверяет допуск собственника к этому подъезду или шлагбауму. Scope токена партнера ограничен этим домом.

## Взаимодействие

- Собственник открывает функцию в мобильном приложении.
- Приложение вызывает tenant-core-app.
- Сервис проверяет допуск по данным собственника и вызывает API партнера.
- Партнер присылает событие звонка или результат распознавания в tenant-core-app. Приложение показывает результат.
